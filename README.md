# tlcautomation.org

Static website for TLC Automation LLC, hosted on Netlify.

- `index.html`: home page
- `workshop.html`, `network.html`, `privacy.html`, `thanks.html`: other pages
- `demo/`: client demo pages
- `partners/`: partner images

No build step. Netlify publishes the repo root as-is. Every push to `main` deploys to production.

Source: github.com/tlcautomation/tlc-site. Deploys are triggered by Netlify's GitHub app.
